# Как устроен shoping67

Это учебный магазин на C# / Windows Forms. Сначала читайте `Program.cs`, затем нужную форму. Классы имеют те же названия, что и файлы. В обычном режиме используются SQL Server LocalDB и вход пользователя; `--demo` открывает магазин без базы.

## Папки проекта

| Папка | Что находится внутри |
| --- | --- |
| `Forms` | Окна: вход, регистрация, магазин, администратор, товар, корзина, акции и настройки почты. |
| `Models` | Структуры данных: товар, пользователь, категория, корзина, заказ, акция. |
| `Data` | Подключение к SQL и сохранение товаров, характеристик и акций. |
| `Services` | Загрузка каталога, фильтры, скидки, оформление заказа, почта и PDF. |
| `Localization` | Выбор языка, применение ресурсов и форматирование текстов. |
| `Resources` | Общие тексты `.resx`, `.en.resx`, `.ru.resx`. Ресурсы конкретного окна лежат рядом с формой. |
| `UI` | Общие кнопки, цвета, логотип, изображения и строка товара. |
| `Catalog`, `Images/Products` | Встроенный каталог реальных моделей и их фотографии. |
| `Migrations` | История структуры базы EF. Эти файлы нужны для обновления существующей базы. |
| `Properties` | Пользовательская настройка `UserLanguage`. |
| `Tools` | Автоматическая проверка окон и подготовка фотографий для GitHub Actions. Это служебные режимы, не второй магазин. |

## Основные файлы

- `Program.cs`: выбор режима, подготовка базы, вход и открытие главного окна.
- `Forms/LoginForm.cs`: проверка имени и пароля; выбор языка справа сверху.
- `Forms/RegisterForm.cs`: создание пользователя с ролью покупателя.
- `Forms/StoreForm.cs`: главная магазина, поиск, фильтры, сортировка и открытие корзины.
- `Forms/AdminForm.cs`: единое управление товарами и акциями, сводка продаж, открытие магазина и настройки почты.
- `Forms/ProductEditorForm.cs`: ввод и изменение товара. Одна форма используется для добавления и редактирования.
- `Forms/PromotionEditorForm.cs`: даты, процент скидки и выбор товаров акции.
- `Forms/EditorForm.cs`: общая основа редакторов — поля и кнопки сохранения/отмены.
- `Forms/CartForm.cs`: количество товаров, email покупателя и кнопка учебной оплаты.
- `Forms/OrderConfirmationForm.cs`: результат покупки, сохранение PDF, повтор отправки письма.
- `Data/AppDbContext.cs`: строка подключения и таблицы EF.
- `Data/ProductService.cs`: проверка и сохранение товара одной транзакцией.
- `Data/ShopSettingsStore.cs`: характеристики, акции и удаление товара с сохранением истории продаж.
- `Services/TechCatalog.cs`: проверенный интернет-каталог, кеш и встроенный запасной каталог.
- `Services/DatabaseShopStore.cs`: товары и покупки в SQL.
- `Services/DemoShopStore.cs`: те же операции в памяти; каталог загружается один раз за запуск.
- `Services/CatalogFilter.cs`: последовательные проверки фильтров.
- `Services/PromotionEngine.cs`: выбор наибольшей подходящей скидки.
- `Services/CheckoutFlow.cs`: порядок «покупка → очистка корзины → письмо», защита от повторной оплаты.
- `Services/EmailSender.cs`: отправка письма через настроенный Gmail.
- `Services/OrderEmail.cs`: текст письма из ресурсов и экранирование данных.
- `Services/OrderPdf.cs`: создание PDF-чека.
- `Services/MailSettings.cs`: хранение настроек почты с шифрованием пароля средствами Windows.
- `Services/Parool.cs`: хеширование и проверка паролей пользователей.
- `Models/ShoppingCart.cs`: добавление, изменение количества и удаление позиций.
- `Models/ShopOrder.cs`: номер заказа, снимок оплаченных позиций, сумма и дата доставки.
- `Models/IShopStore.cs`: общий набор операций для SQL и демонстрационного режима.

Названия моделей `Toode` (товар), `Kategooria` (категория), `Kasutaja` (пользователь), `Muuk` (продажа) сохранены для совместимости с существующей базой. Таблицы не переименовываются, миграции и история продаж остаются.

## Как проходит покупка

1. `StoreForm` получает товары из `IShopStore` и показывает их.
2. `ShoppingCart` хранит выбранные позиции и количества.
3. `CartForm` передаёт корзину и email в `CheckoutFlow`.
4. Хранилище заново проверяет цены и остатки. В SQL изменение остатков и запись продаж выполняются вместе.
5. `CheckoutFlow` очищает корзину и вызывает `EmailSender`.
6. `OrderEmail` и `OrderPdf` создают подтверждение на языке оформления заказа.

Ошибка отправки почты не повторяет покупку. Кнопка повторной отправки отправляет тот же заказ.

## Что убрано и почему

Удалены старые `Form2`/`Form3`, прежняя карточка `Toodekaart`, `PoodToode`, старый генератор чека, неиспользуемый импорт Fake Store API и отдельный устаревший демонстрационный каталог с картинками. Добавление товаров и сводка продаж перенесены в `AdminForm`, поэтому функции администратора сохранены.

`ShopStyle` и `Shop67Ui` заменены одним `ShopUi`. Классы из больших файлов `Shop67Model`, `ShopProduct`, `ShopAdminForm` разделены по назначению. Два демонстрационных хранилища объединены в одно. Пустой Designer магазина удалён: этот экран строится кодом. Designer-файлы входа и регистрации нужны и сохранены.

## Что важно помнить

- Оплата учебная, доставка «через 14 дней» расчётная. Письмо при настроенном Gmail отправляется по-настоящему.
- Цены и остатки каталога учебные; это не актуальный склад поставщика.
- В SQL данные сохраняются, в `--demo` остатки восстанавливаются после перезапуска.
- GitHub хранит код и встроенный каталог. Локальная база и настройки Windows на школьном ПК могут очищаться.
- В старой таблице товара цена остаётся `float`; расчёты магазина используют `decimal`. Изменение типа колонки потребовало бы отдельной миграции.
- Тексты интерфейса переведены на три языка. Произвольный текст, написанный администратором, автоматически не переводится.

## Проверки

```powershell
dotnet build Tooded_2.slnx
dotnet run --project Tests/Shop.CoreChecks
dotnet run --project Tests/Shop.StorageChecks
dotnet run --project Tooded_2 -- --ui-check
```

Основные проверки тестируют корзину, скидки, фильтры и ресурсы трёх языков. Проверки хранения работают с отдельной SQLite-базой в памяти, проверяют создание/редактирование/удаление товаров и PDF. Проверки окон на Windows переключают языки в открытых формах и проверяют сохранность введённых данных. Тесты не отправляют настоящие письма.
